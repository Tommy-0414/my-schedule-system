#  學生專屬免費線上行程表與排程系統 (Schedule Hub)

這是一個專為學生與背包客打造的**完全免費、免註冊、免花錢租網域**的線上行程管理工具！利用靜態網頁技術與 Google 試算表做為雲端資料庫，達到零維護成本的極致效能。

**線上展示 (Live Demo):** https://my-schedule-v3.netlify.app/

## 核心特色
- **永久免費：** 不需購買伺服器或租借昂貴網域，利用 Netlify 與 Google 試算表完美結合。
- **免註冊帳號：** 隱私百分百安全，資料直接存放在你自己的 Google 試算表中。
- **智慧週期批量生成：** 支援每天、每週特定日期的行程自動大量產生，並支援天數自動計算。
- **秒級排序與即時微調：** 系統會自動依時間軸進行排序，並支援表格內直接點擊修改。
